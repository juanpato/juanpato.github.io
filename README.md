## Sobre el sitio

Portfolio de una sola página, estático y autocontenido: todo el HTML, CSS y
JavaScript viven en `index.html`, sin dependencias ni proceso de build. Se sirve
directamente con GitHub Pages.

- Diseño oscuro tipo *tech*, responsive y con animaciones de entrada.
- Sección de proyectos en producción, trayectoria profesional y stack técnico.
- CV descargable en PDF.

## Stack del sitio

- HTML5 / CSS3 (CSS variables, grid, flexbox)
- JavaScript vanilla (sin frameworks)
- Tipografías: Bricolage Grotesque · Hanken Grotesk · JetBrains Mono
- Hosting: GitHub Pages

## Ver el sitio localmente

No requiere build. Alcanza con abrir `index.html` en el navegador, o levantar
un servidor estático simple:

```bash
# con Python
python -m http.server 8000
# luego abrir http://localhost:8000
```
